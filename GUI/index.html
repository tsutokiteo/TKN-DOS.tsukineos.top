// 项目概述

TsukineOS x16 是一个运行在 TKN-DOS 之上的 16-bit GUI 图形外壳。 它为 TKN-DOS 提供最基础的图形界面：窗口、菜单、鼠标支持。

它在项目家族中的定位类似于 Windows 1.0 之于 MS-DOS： 不是独立的操作系统，而是运行在 DOS 之上的图形环境。

// 层级关系

┌─────────────────────────────────────┐ │ TsukineOS x16 (GUI 外壳) │ │ 窗口 · 菜单 · 鼠标支持 │ ├─────────────────────────────────────┤ │ TKN-DOS (16-bit 实模式系统) │ │ 命令行 · FAT12/16 · 中断服务 │ └─────────────────────────────────────┘ │ ▼ 硬件层 (x86 16-bit 实模式)

⬆ TsukineOS x16 必须运行在 TKN-DOS 之上，不能独立存在。

// 设计目标

  • 为 TKN-DOS 提供 最基本的图形界面
  • 支持 窗口管理（移动/缩放/重叠）
  • 支持 鼠标输入（通过串口或 PS/2）
  • 提供 简单的菜单栏 和 应用程序启动
  • 保持 极低的内存占用（< 256KB）

// 技术规格

架构 · x86 16-bit 实模式

运行环境 · TKN-DOS（宿主系统）

图形模式 · VGA 文本模式 / VGA 图形模式 (320x200 / 640x480)

输入 · 键盘 + 鼠标（通过 INT 33h 或串口）

内存占用 · 目标 < 256KB

NASM OpenWatcom C VGA INT 33h TKN-DOS API

// 项目家族中的位置

  • TsukineOS → 衍生出 TKN-DOS
  • TKN-DOS → 作为 TsukineOS x16 的宿主系统
  • TsukineOS x16 → 附属项目，运行在 TKN-DOS 之上

// 与 Windows 1.0 的类比

MS-DOS → TKN-DOS

Windows 1.0 → TsukineOS x16

就像 Windows 1.0 不是独立的操作系统，而是运行在 MS-DOS 之上的图形外壳一样， TsukineOS x16 也不是独立的系统，而是 TKN-DOS 的图形扩展。

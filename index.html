// 项目概述

TKN-DOS 是一个 从零构建的 16-bit 实模式 DOS 兼容系统， 完全自研（汇编 + C），不依赖任何现有操作系统代码。 它将提供轻量、可定制的命令行 + TUI 环境，作为复古硬件与现代开发之间的桥梁。

作为 TsukineOS 的衍生项目， 同时也作为 TsukidaOS 的内核模块，为其提供 16-bit 实模式兼容层。

// 设计规格

架构 · x86 16-bit Real Mode

引导方式 · BIOS (MBR) + UEFI (GRUB) 双启

文件系统 · FAT12 / FAT16

Shell · TKN.COM (自研命令解释器)

包管理 · 轻量级 .TKN 包格式

L2R 层 · 16 ↔ 64-bit 模式切换

NASM OpenWatcom C FAT12/16 BIOS/UEFI L2R

// 双重身份

  • 独立系统：可作为完整的 DOS 环境启动，运行 16-bit 程序。
  • TsukidaOS 内核模块：作为翻译层，为 TsukidaOS 提供 16-bit 实模式兼容。

💡 独立时 → 完整 DOS 系统 · 集成时 → TsukidaOS 的 16-bit 翻译层

// 项目家族中的位置

  • TsukineOS → 衍生出 TKN-DOS
  • TKN-DOS → 作为 TsukineOS x86-16bit 的宿主
  • TsukidaOS → 内部集成 TKN-DOS 作为 L2R2Java 层
